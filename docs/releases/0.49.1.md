# Home Center 0.49.1

Status: official release.

## Кратко

Home Center 0.49.1 — исправляющий релиз линии 0.49, который закрывает нарушение границы канала автоматического обновления, обнаруженное после публикации 0.49.0.

## Исправление канала обновлений

Автоматический updater и его установщик по умолчанию теперь используют только подтверждённый Public Stable источник `ControlCenterSoft/home-center-stable`.

Updater принимает release metadata и download URL только из Public Stable репозитория. Ссылки на `home-center-development` больше не являются допустимым источником автоматического обновления по умолчанию.

Это восстанавливает обязательную границу: установленная Stable-система не должна автоматически выбирать development-релиз только потому, что его SemVer выше текущего Stable.

## Безопасность и коммерческая граница

Исправление fail-closed: release metadata, artifact URL, GitHub asset digest и checksum sidecar продолжают проверяться до rollout. Сохраняются блокировка повторного развёртывания quarantined digest, проверка идентичности узлов, rolling-порядок peer-first и rollback при ошибке.

Остальные security/privacy/infrastructure-neutrality и module legal/commercial compliance границы 0.49.0 не ослабляются.

## Установка и обновление

Переход с 0.49.0 на 0.49.1 выполняется штатным поддерживаемым upgrade-путём. Пользовательские данные, установленный пароль администратора, Household state и локальная конфигурация не должны сбрасываться.

Для HA применяется безопасный rolling-порядок: peer/standby обновляется первым, затем выполняются health и identity checks, после чего обновляется coordinator. При ошибке переход ко второму узлу запрещён, а неуспешный artifact digest карантинируется.

## Квалификация релиза

Exact source revision 0.49.1 должен пройти полный GitHub-hosted CI для Python 3.12/3.13, полный pytest, воспроизводимую сборку wheel, public-repository privacy boundary и infrastructure-neutrality. Отдельные regression tests обязаны подтверждать, что updater и installer используют `home-center-stable` и не содержат `home-center-development/releases` как допустимый default update channel.

Официальная source-публикация и Public Stable promotion остаются отдельными защищёнными этапами. Public Stable допускается только для той же квалифицированной release identity.
