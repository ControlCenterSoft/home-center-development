# Home Center 0.43.0

Статус: официальный source release; версия также опубликована в Public Stable.

## Состав релиза

Home Center 0.43.0 связывает канонический набор требований к контрактам Home Service, введённый в 0.42.0, с точным evidence совместимости Home Service, которое фактически проверило эти требования.

`home-center.module-home-service-contract-requirement-binding.v1` задаёт этой связи детерминированную identity `mhsrb-*`. Evidence связывает один точный набор требований `mhscr-*` с одним точным compatibility binding `mhscb-*` и фиксирует версию Home Center, identity/версию модуля, identity Home Service, digest профиля сервиса, канонические требуемые revisions контрактов и результат совместимости.

Binder повторно строит compatibility из канонического requirement set, module contract/admission binding и профиля Home Service. Набор требований, у которого версия Home Center, identity/версия модуля, identity сервиса или требуемый набор контрактов не совпадают с полученным контекстом совместимости, отклоняется fail-closed.

Это делает происхождение требований проверяемым, не изменяя существующие v1-контракты requirement set и Home Service compatibility.

## Граница безопасности

Requirement-binding evidence носит только описательный характер. Оно не разрешает admission, установку, execution, production mutation или external publication. Состояние blocked остаётся валидным evidence, но никогда не предоставляет runtime-полномочий.

Контракт topology-neutral и infrastructure-neutral. Он не добавляет Jobs/Operations behavior, Cluster/HA orchestration, placement semantics или скрытый release-promotion path. Существующая политика аутентификации не меняется.

Миграция постоянного состояния не требуется.

## Проверка релиза

Опубликованная release identity должна соответствовать точному квалифицированному исходному дереву. Обязательные release gates включают проверки контрактов, безопасности и privacy boundary, воспроизводимости артефактов и infrastructure-neutrality. Публикация версии сама по себе не предоставляет production mutation authority; установка и активация выполняются только через штатный проверяемый update path.
