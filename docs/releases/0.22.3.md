# Home Center 0.22.3

Home Center 0.22.3 is the production rollout hotfix for the 0.22 web-interface repair.

The release retains the repaired canonical `/static/app.css` and `/static/app.js` routes, responsive mobile-first interface, same-origin authentication and mandatory first-login administrator password change.

During qualification of 0.22.2, the two-node rolling updater correctly detected that the legacy deployment profile was stored below `/opt/home-center/current`. A successful node switch therefore changed the path target and caused the new process to lose that node-local profile. 0.22.3 fixes the migration transaction: before either node is switched, the verified installer atomically copies the existing deployment profile to `/etc/home-center/deployment-profile.json`, validates it as a JSON object, preserves ownership and permissions, and atomically updates the existing Home Center configuration to the persistent path. Existing persistent or explicitly external profile paths are validated and preserved.

The migration is backward-compatible with rollback to the previous release because both old and new control-plane code accept the configured absolute deployment-profile path. The artifact SHA-256, peer-first rolling order, state-database backup, rollback and post-deployment cluster verification remain fail-closed.

This patch does not expand the 0.22 execution boundary or create a new production mutation path. Worker handoff evidence still cannot authorize that transition by itself.
