# Home Center 0.22.3

Home Center 0.22.3 — исправление линии 0.22, предназначенное для безопасного обновления встроенного Web-интерфейса и двухузловой установки.

Релиз сохраняет исправленные канонические маршруты `/static/app.css` и `/static/app.js`, адаптивный mobile-first интерфейс, same-origin authentication и обязательную смену первоначального пароля администратора при первом входе.

Исправлена миграция deployment profile в rolling-update сценарии. Если legacy-профиль расположен внутри `/opt/home-center/current`, до переключения любого узла установщик атомарно копирует его в постоянное расположение `/etc/home-center/deployment-profile.json`, проверяет, что файл является корректным JSON-объектом, сохраняет ownership/permissions и атомарно обновляет конфигурацию Home Center на новый путь. Уже постоянные или явно внешние пути профиля проверяются и сохраняются без переноса.

Миграция совместима с откатом на предыдущую версию: предыдущий и новый control-plane принимают настроенный абсолютный путь deployment profile. Проверка SHA-256 артефакта, порядок обновления peer-first, резервная копия state database, rollback и итоговая проверка состояния после обновления сохраняют fail-closed поведение.

Патч не расширяет исполнительную границу линии 0.22 и не создаёт новый путь изменения пользовательской инфраструктуры. Evidence выполнения само по себе не является разрешением на дополнительное изменение состояния.
