# Home Center 0.45.0

Status: source package ready for qualification.

## Scope

Home Center 0.45.0 adds a canonical aggregate identity for one module's
requirements across multiple Home Services.

`home-center.module-home-service-contract-multi-requirement-set.v1` combines
existing exact `mhscr-*` single-service requirement sets into one deterministic
`mhsmr-*` evidence object. The aggregate preserves each service identifier,
single-service requirement-set identity and exact versioned service/API
contracts.

Input order does not affect identity: service requirements are canonicalized by
service identifier. Duplicate service requirements, mixed Home Center/module
contexts, malformed or tampered nested requirement identities, non-canonical
serialized order and authority-bearing evidence are rejected fail-closed.

## Safety boundary

The aggregate is evidence only. It never authorizes admission, installation,
execution, production mutation or external publication.

The contract is topology-neutral and infrastructure-neutral. It adds no
Jobs/Operations behavior, Cluster/HA orchestration, placement semantics or
release-promotion logic. Existing authentication policy is unchanged.

No persistent-state migration is required.

## Qualification boundary

Runner-free source preparation includes the runtime contract, closed JSON
Schema and targeted unit/contract tests. Repository-wide qualification,
security/privacy evidence and release promotion remain the responsibility of
HC Release Engine A/B.
