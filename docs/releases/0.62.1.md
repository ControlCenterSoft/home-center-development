# Home Center 0.62.1

Status: official release.

Release profile: `single-node-core`.

## Назначение

Home Center 0.62.1 — lineage-corrective patch-релиз функциональной линии 0.62. Он не расширяет продуктовую capability относительно квалифицированного 0.62.0: его задача — сохранить тот же безопасный role-driven identity/account provisioning boundary и одновременно восстановить доказуемую release ancestry от официального Public Stable 0.61.2.

0.62.0 был технически квалифицирован и опубликован как immutable source release, но guarded Public Stable promotion корректно обнаружил, что его Git history не является потомком exact approved-source 0.61.2. Содержимое split-routing fail-closed correction присутствовало, однако ancestry gate обязан работать по точной истории, а не по предположению о byte-equivalence. 0.62.1 создаётся только после history-only reconciliation, где canonical 0.62 tree сохранён byte-for-byte, а exact 0.61.2 source revision добавлен в ancestry без переписывания `v0.62.0`.

## Функциональная граница

0.62.1 сохраняет квалифицированный 0.62 boundary:

- typed local/directory identity-provider capability и exact Household/member/role/policy/provider binding;
- content-addressed provisioning plan и server-side account-absence preflight;
- qualification-bound provider registry и запрет generic self-declared production adapter;
- explicit confirmation перед provider execution;
- только bounded `secret://` references без credential values;
- durable Job до side effect, single-invocation mutation и обязательный read-back/post-condition verification;
- provider acceptance не считается успехом, ambiguous outcome остаётся fail-closed;
- отдельный confirmed `/bind` использует только persisted verified execution receipt и не reinvoke-ит provider;
- backup/restore verified execution/binding evidence.

## Security и claims

Релиз наследует exact 0.61.2 split-routing fail-closed security correction через явную reconciled ancestry. Не заявляются без отдельной qualification universal concrete provider execution, portable home/profile для неподтверждённого provider, multi-node HA/automatic failover и commercial-launch clearance. Эти возможности остаются disabled/fail-closed/unclaimed и не превращаются в синтетический PASS.

0.62.1 не выдаёт generic shell, sudo/root/directory-admin authority, не изменяет emergency `admin`, не принимает password/token values через product API и не публикует сервисы наружу.

## Upgrade / rollback

Обязательная release qualification выполняется на exact identity **0.61.2 → 0.62.1 → 0.61.2** с сохранением SQLite state, конфигурации, пользовательских данных, admin password, sessions/Audit, systemd units и enabled/active state. Existing `v0.62.0` остаётся immutable и не используется как источник перенесённого PASS.

Public Stable promotion допускается только после exact-head Python 3.12/3.13/3.14 CI, reproducible artifact qualification, hosted install/upgrade/rollback, real-systemd health/rollback, CodeQL security-extended, privacy/infrastructure-neutrality checks и полного release artifact set.
