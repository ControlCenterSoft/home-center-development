# Home Center 0.27.0

Status: development qualification candidate.

Home Center 0.27 continues the Household/Intent foundation introduced in 0.26 by adding a versioned persistence boundary for household state. The new boundary is deliberately limited to Home Center product state: it does not execute provider actions or authorize infrastructure mutation.

## Versioned household state

`home_center.household_store` adds deterministic `HouseholdSnapshot` and `HouseholdCommit` evidence together with a reference `HouseholdStore` implementation.

The store provides:

- create-once semantics for a household identifier;
- monotonically increasing household generation;
- deterministic snapshot and resource-version identifiers;
- explicit previous-snapshot linkage;
- optimistic concurrency for replacement using the exact expected resource version;
- fail-closed rejection of stale writes, duplicate creation and missing state.

A failed stale replacement leaves the current snapshot unchanged. Household validation from 0.26 remains authoritative, including the requirement for at least one enabled parent and valid member/device bindings.

## Safety boundary

Persistence evidence carries fixed non-authority flags:

- `infrastructure_mutation_authorized = false`;
- `external_publication_authorized = false`.

Storing Household state therefore does not create accounts, modify professional RBAC, configure DNS/VPN/MDM, mutate external Desired/Actual State, enroll devices or run provider commands. Later execution integration must consume an exact fresh resource version and pass the normal Home Center authorization/change/execution boundaries.

## Contracts and tests

A closed JSON contract is added for household snapshots and commits. Tests cover deterministic create evidence, generation/previous-snapshot linkage, exact-resource-version replacement, stale-write rejection without state drift, duplicate creation and missing-state handling.

Release identity is `0.27.0` across VERSION, package metadata and runtime metadata. No external service or infrastructure migration is introduced by this candidate.

## Cumulative guarantees

The 0.22–0.25 durable home-service transition guarantees and the 0.26 Household/Intent planning guarantees remain cumulative. This release adds product-state persistence only and does not weaken confirmation, authorization, audit or recovery boundaries.

The 0.27 branch remains a development candidate until its complete acceptance and release gates pass.
