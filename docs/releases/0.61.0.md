# Home Center 0.61.0

Status: development foundation; not Release Candidate and not Public Stable.

Canonical Public Stable at preparation time is 0.58.0. This work stays inside the permitted three-release window 0.59–0.61 and is stacked on the prepared 0.60 parental Internet policy foundation.

Implemented in this source-only slice:

- deterministic VPN egress provider evidence for location, reachability, latency and stability;
- explicit provider/parental/system DNS strategy;
- bounded split-domain routing policy;
- explicit kill-switch and fallback semantics;
- exact binding to the 0.59 composed Household policy and optional 0.60 parental policy identity;
- parental DENY precedence before any VPN or direct route decision;
- closed JSON contracts for provider evidence, policy, current observation and route decision;
- fail-closed tests prepared for later runner qualification.

Current Household role presets are unchanged. In particular, 0.61 does not grant VPN capability to a member whose effective policy has `vpn_allowed=false`.

This slice is planning/evidence only. It does not claim that VPN networking is active and does not grant infrastructure mutation or external publication authority.
