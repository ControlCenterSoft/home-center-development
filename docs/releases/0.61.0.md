# Home Center 0.61.0

Status: official release.

Release profile: `single-node-core`.

## Назначение

Home Center 0.61.0 добавляет provider-neutral VPN egress policy поверх официального Home Center 0.60.0 Public Stable. VPN не является обходным каналом: более строгий parental `DENY` всегда имеет абсолютный приоритет над VPN и direct egress.

## Что входит в релиз

- provider/location evidence с точной идентичностью provider/version/location;
- bounded reachability, latency и stability evidence;
- deterministic provider selection и route decision;
- full и split routing semantics;
- явная DNS strategy: `provider`, `parental` или `system`;
- bounded split-routing domain set;
- kill switch и fallback semantics с fail-closed contradiction checks;
- exact binding к composed Household policy и, при наличии, parental Internet policy;
- strict storage/transport reconstruction provider, policy, observation и route-decision evidence;
- Cozy и Full UI projections без execution authority;
- reproducible wheel и exact node deployment candidate обязаны содержать весь интегрированный 0.61 VPN runtime и четыре закрытых JSON contracts.

## Safety boundary

Provider selection is not VPN activation. Provider observation является только read-only evidence.

Bounded `single-node-core` профиль 0.61.0 не регистрирует и не вызывает concrete production VPN adapter, не конфигурирует VPN client, routing table, DNS service или firewall, не передаёт credentials/secret values и не выдаёт generic shell, infrastructure mutation или external publication authority.

Parental filtering остаётся authoritative. VPN policy не может превратить `vpn_allowed=false` в true. При связанной parental policy использование system DNS запрещено, а policy требует kill switch и deny fallback. Неоднозначный provider outcome запрещено автоматически повторять.

Concrete VPN provider execution, network/firewall/routing mutation и post-condition success могут быть заявлены только после отдельной exact-bound typed provider qualification, durable Job/Audit, повторной exact-state revalidation, pre-mutation recovery boundary и обязательного Actual State read-back. До этого соответствующие возможности остаются fail-closed/disabled/unclaimed.

Multi-node HA / automatic failover также не заявляются без собственной qualification. Отсутствие этих optional claims не подменяется фиктивным PASS и не блокирует технически квалифицированный bounded Stable профиль.

## Install / upgrade / rollback

Release qualification использует immutable identities: официальный Home Center `v0.60.0` source identity `88634f6bf5e35d432581d58327bdb277b9b71140` как baseline и exact 0.61.0 candidate без переписывания candidate source во время теста.

Поддерживаемый переход 0.60.0 → 0.61.0 обязан подтвердить install/upgrade, `/readyz`, restart, сохранность пользовательского состояния и локальных credentials, а также rollback обратно к 0.60.0. Real-systemd rehearsal выполняется на hosted Python 3.12 leg; остальные supported Python legs сохраняют полную source/contract/reproducibility qualification.

## Security и release evidence

Public Stable promotion допускается только после exact-head Home Center CI на Python 3.12/3.13/3.14, complete tests/import/contracts, reproducible artifact qualification, CodeQL Python `security-extended` fail-closed current-source gate, Public repository privacy boundary и Infrastructure neutrality.

Финальный release set должен содержать immutable source/deployment artifacts, обязательный `.sha256` sidecar, `SHA256SUMS`, acceptance/release manifests, sanitized public provenance v2 и SPDX SBOM, связанные с одной точной release identity.

False Success является release blocker: provider selection, observation или command acceptance не могут отображаться как активный/успешно применённый VPN без обязательного post-condition evidence.

## Commercial / legal boundary

0.61.0 не добавляет concrete bundled VPN provider и не вводит новую provider-specific runtime dependency. Технический Public Stable не является automatic commercial launch clearance. Если в будущем добавляется конкретный VPN provider или коммерчески заявляется соответствующая capability, для него требуется отдельное license/source/distribution/notice/support evidence.

## Совместимость

Home Center 0.61.0 остаётся полноценным local-first single-node продуктом. Concrete VPN execution, network mutation, multi-node HA/automatic failover и commercial launch clearance остаются отдельными fail-closed/unclaimed capabilities до собственной qualification.
