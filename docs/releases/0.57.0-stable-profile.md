# Home Center 0.57.0 — bounded Public Stable profile

This profile defines the claims allowed for the first official Public Stable promotion of 0.57.0 under HC-RM-1.2.

## Qualified core claim

The release may be promoted as a **single-node technical Public Stable** only after the exact release identity has passed the normal CI/source/artifact/security gates, supported upgrade and rollback checks, user-state preservation checks, and the complete public release artifact set (source/deployment digests, checksum sidecar, SHA256SUMS, qualification/acceptance/release manifests, provenance and SPDX SBOM).

Provider command acceptance is never enrollment success. The 0.57 runtime must continue to keep `enrollment_completed=false`, `post_condition_verified=false` and `managed_state_change_authorized=false` until a later verified post-condition boundary authorizes a managed-state transition.

## Claims intentionally excluded from the bounded Stable profile

- **Concrete provider execution support:** not claimed unless an exact candidate-bound production-capable provider adapter has completed its own qualification. With no qualified adapter registered, `start` remains fail-closed.
- **Multi-node HA/restart support for the new execution profile:** not claimed unless exact-bound real target and multi-node HA/restart evidence exists for the promoted artifact.
- **Commercial launch/legal clearance:** not claimed by technical Public Stable. Commercial/legal clearance remains a separate bounded evidence track and may gate commercial launch or commercial claims without blocking technical Stable.

These exclusions are not waivers. They are explicit unsupported-capability boundaries. The product must not silently enable or advertise an excluded capability.

## Non-negotiable release blockers

The bounded profile does not weaken security, privacy, infrastructure-neutrality, reproducible artifact identity, install/upgrade compatibility, rollback/recovery, user-state preservation, checksum/provenance, no-secret boundaries, or false-success protections. Any failure in those core gates blocks Stable promotion.

A positive bounded-profile evaluation does not itself grant publication authority, provider execution authority, HA authority or external-publication authority.
