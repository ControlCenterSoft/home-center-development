# Home Center 0.16.0

Infrastructure-neutral compute release integration.

- Proxmox is represented as a provider discovered from runtime-supplied snapshots.
- VM and LXC lifecycle engines are plan-only and provider-agnostic at the orchestration boundary.
- Resource placement works across arbitrary eligible providers and failure domains.
- No cluster URL, host name, IP address, credential, or environment identifier is compiled into the product source.
