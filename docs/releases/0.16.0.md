# Home Center 0.16.0

Cumulative portable compute release: verified stable runtime plus 0.15 inventory/discovery/profiles, runtime-discovered Proxmox provider, VM/LXC plan-only lifecycle and provider-neutral resource placement.

The compute boundary is fail-closed: malformed or inconsistent observations are rejected, a guest must fit a single eligible node, and an HA guest requires two eligible nodes with failover capacity. Lifecycle and placement results never grant production mutation authority.

Release ordering is strict: 0.16.0 inherits the complete 0.15.0 foundation and must not enter a release channel before 0.15.0 is accepted there.
