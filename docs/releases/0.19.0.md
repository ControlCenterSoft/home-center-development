# Home Center 0.19.0

Home Center 0.19 starts the home-service Market lifecycle on top of the
qualified 0.15–0.18 infrastructure, compute, automation, certificate and
authorization foundation.

The first cumulative boundary includes typed profiles for Yandex Smart Home,
TorrServer, torrent client, ZigBee bridge, Minecraft Server and Android MDM.
Every profile declares capabilities, minimum storage, backup policy and the
complete install/configure/health/update/backup/restore/remove lifecycle.

Deployment remains fail-closed and plan-only. Node capabilities and free
storage are checked before planning. External publication is never implicit:
local-only services reject it, while other services require both an explicit
request and a dedicated publication capability. Approval does not grant
execution authority, and no 0.19 contract performs production mutation.
