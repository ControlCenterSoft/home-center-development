# Home Center 0.22.1

Home Center 0.22.1 is a focused web-interface hotfix for the 0.22 release line.

The built-in UI now references its CSS and JavaScript through the server's canonical `/static/` route, preventing the unstyled HTML fallback that could appear after deployment. The technical interface also provides a usable same-origin sign-in flow for local administrator and configured AD authentication, handles the mandatory first-login local administrator password change, and renders the current infrastructure inventory in a responsive mobile-first layout.

This patch does not expand the 0.22 execution boundary or introduce new production mutation paths. Worker handoff evidence still cannot authorize that transition by itself, and the existing authorization, audit, TLS, deployment and rollback boundaries remain unchanged.

The release artifact includes the repaired static assets and is suitable for the existing two-node rolling updater, which applies the peer node first and the coordinator second.
