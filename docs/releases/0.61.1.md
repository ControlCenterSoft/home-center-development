# Home Center 0.61.1

Status: official release.

Release profile: `single-node-core`.

## Назначение

Home Center 0.61.1 — корректирующий релиз линии VPN egress policy поверх официального Public Stable 0.60.0. Он сохраняет функциональную границу 0.61.0 и закрывает fail-closed дефект split routing до Public Stable promotion.

Опубликованный source release `v0.61.0` остаётся неизменяемой исторической identity и не переписывается. Исправленный release train получает новую exact identity `0.61.1`.

## Security correction

- split-route direct egress разрешается только при явном `fallback_mode=direct` и выключенном kill switch;
- при `kill_switch=true` или `fallback_mode=deny` non-matching split-route domain завершается fail-closed с `DENY`, а не выходит напрямую;
- strict storage/transport reconstruction проверяет согласованность `route` и `reason`, поэтому DIRECT/DENY evidence нельзя переименовать в противоречивый outcome;
- closed JSON Schema фиксирует те же route/reason constraints;
- Cozy/Full projection принимает новый fail-closed reason `split_route_direct_not_authorized` и отображает его как блокировку, а не как invalid/unknown outcome;
- parental `DENY` сохраняет абсолютный приоритет.

## Сохраняемая 0.61 boundary

- provider/version/location evidence и deterministic selection;
- full/split routing decision surface;
- explicit DNS strategy;
- kill-switch/fallback semantics;
- exact binding к Household/parental policy;
- Cozy/Full evidence projections;
- отсутствие concrete provider/network mutation authority в bounded Stable profile.

Provider selection is not VPN activation. Concrete production VPN adapter execution, network/firewall/routing mutation, Multi-node HA / automatic failover и commercial launch clearance не заявляются без отдельного qualified evidence и остаются fail-closed/unclaimed.

## Install / upgrade / rollback

Обязательная qualification выполняется на exact release identity без source rewrite. Базовый supported path для Public Stable promotion — `0.60.0 → 0.61.1` с install/upgrade, readiness/restart, сохранностью state/credentials и rollback обратно к 0.60.0.

## Release evidence

Public Stable promotion допускается только после exact-head Python 3.12/3.13/3.14 CI, reproducible artifact qualification, CodeQL security-extended fail-closed gate, privacy/infrastructure-neutrality checks и полного checksum/provenance/manifest/SBOM release set. False Success остаётся release blocker.
