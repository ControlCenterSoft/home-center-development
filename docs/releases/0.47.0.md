# Home Center 0.47.0

Status: development candidate.

Home Center 0.47 completes the first mobile-first navigation boundary for the **«Уютный»** interface while preserving the professional **«Полный»** interface introduced as an explicit user-selectable mode in 0.46.

## Full «Уютный» navigation

The Cozy interface now has three first-class screens:

- **Домой** — understandable overall state, server/capability summary and a focused list of items requiring attention;
- **Семья** — household-oriented people/device surface designed around `FamilyMember`, household roles and effective policy rather than low-level infrastructure objects;
- **Мой дом** — household capability catalogue for Internet, Smart Home, media, games, files, servers and backups.

The selected Cozy section is persisted in browser-local UI state and restored on subsequent openings.

## Mobile-first behavior

- On desktop the Cozy navigation is a compact side rail.
- On mobile it becomes a bottom navigation bar with large touch targets.
- Content uses household terminology and hides provider-specific implementation details.
- The professional Full mode remains available through the global mode switch at all times.

## Read-only release boundary

0.47 deliberately keeps the new Cozy screens on the existing read model. The UI does not introduce POST/mutation calls or a parallel execution path.

The «Семья» screen can render household members when the read model exposes them, but creation/provisioning is intentionally disabled in this release. Role-driven provisioning, provider execution and protected Household/Intent changes remain a 0.48+ boundary and must pass the normal Home Center authorization, plan/desired-state, audit, stale-state, post-condition and recovery controls.

## «Мой дом» capability mapping

Household service cards are derived from the actual capability list and node inventory rather than hard-coded claims of availability. A household feature is shown as available only when the current read model supplies a matching capability (or, for the Server card, at least one detected node).

## Safety and compatibility

- «Уютный» remains the default ordinary-home presentation.
- «Полный» remains available without data migration.
- Mode/section switching is presentation-only.
- No new mutation endpoint is introduced.
- External publication, NAT/port-forwarding and other risk-bearing actions remain unchanged and are not enabled by the Cozy UI.

## Release identity

Release identity is `0.47.0` across `VERSION`, Python package metadata and runtime package metadata.

The candidate remains development-only until complete qualification and release gates pass.
