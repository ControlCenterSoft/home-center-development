# Home Center 0.29.0

Status: development qualification candidate.

Home Center 0.29 adds a fail-closed compatibility admission boundary for
cryptographically verified Module Manifest v2 artifacts. The package determines
whether a verified module is compatible with one exact Home Center runtime
context without installing, starting, updating, removing, or otherwise executing
the module.

## Compatibility-aware module admission

`home_center.module_admission.evaluate_module_compatibility()` consumes an
already validated Module Manifest v2 plus the exact
`VerifiedModuleArtifact` evidence produced by the module artifact verifier.

Before compatibility is evaluated, the admission boundary re-binds:

- module ID and module version;
- publisher identity;
- manifest binding SHA-256;
- artifact SHA-256 and artifact size;
- the content-addressed object-store key;
- exact provenance statement SHA-256;
- the threshold-satisfying verified signing-key set declared by the manifest.

A mismatch is rejected as invalid evidence rather than converted into a normal
compatibility result.

## Runtime compatibility snapshot

The decision binds one bounded runtime snapshot:

- exact Home Center semantic version;
- architecture and operating-system identifiers;
- available capability identifiers;
- installed module IDs and exact semantic versions.

The verified provenance evidence and runtime inputs are validated, normalized
and sorted before the deterministic decision ID is calculated. Reordering
capabilities or installed-module input therefore cannot change the result.

Admission is blocked when any of these conditions is true:

- the Home Center version is outside the manifest's half-open compatibility
  interval;
- the runtime architecture or operating system is not declared supported;
- a required capability is unavailable;
- a required dependency is absent;
- an installed dependency, including an optional dependency when present, is
  outside its declared version interval;
- a declared conflicting module is installed.

## Safety boundary

`home-center.module-admission-decision.v1` is compatibility evidence only.
Every decision fixes:

- `installation_authorized = false`;
- `execution_authorized = false`;
- `production_mutation_enabled = false`;
- `external_publication_authorized = false`.

A `compatible` result therefore does not authorize installation, lifecycle
execution, provider commands, network changes, service mutation, or publication.
Those remain separate protected product operations outside this package.

## Contracts and tests

A closed JSON Schema is added for the deterministic admission decision.
Targeted tests cover successful compatibility, deterministic normalization,
Home Center/platform mismatch, missing capabilities, dependency version
enforcement, optional dependency handling, conflicts, verified-artifact binding,
duplicate runtime evidence, and the non-authorizing contract constants.

Release identity is `0.29.0` across VERSION, Python package metadata, and runtime
package metadata. No data migration is required: this candidate adds a
side-effect-free module compatibility decision over existing Manifest v2 and
verified-artifact contracts.

The 0.29 branch remains a development candidate until its complete qualification
and release gates pass.
