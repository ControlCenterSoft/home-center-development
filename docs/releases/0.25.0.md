# Home Center 0.25.0

Status: development qualification candidate.

Home Center 0.25 closes the evidence chain around the durable home-service
transition path by appending read-back verification results to the same
hash-chained audit store used by the authorized apply boundary.

## Completion audit

`record_transition_completion_audit()` accepts only a previously audited apply
receipt, the matching `home-service-transition-verification.v1` result and the
same Home Center state store.

Before appending completion evidence it verifies:

- exact receipt, authorization, commit, decision and instance binding;
- expected state, generation and resource version from the apply receipt;
- non-mutating verification flags;
- presence of the original pre-apply audit event in the local audit chain;
- action, outcome, correlation and transition identifiers of that pre-apply event.

A missing or mismatched pre-apply audit event fails closed and does not append a
completion record.

## Verified and drifted outcomes

A verified read-back appends `home-service.transition.apply.verified`; detected
drift appends `home-service.transition.apply.drifted`. Both records bind the
pre-apply audit event, verification, apply receipt, expected and observed state,
generation/resource version and all mismatch codes.

The returned `home-service-transition-completion-audit.v1` record is evidence
only. It explicitly carries `service_state_mutation_authorized=false` and
`further_mutation_authorized=false`.

## Artifact and contract boundary

- Release identity is `0.25.0` across VERSION, package metadata and runtime metadata.
- The wheel must include apply, pre-apply audit, read-back verification and completion-audit runtime modules.
- The completion-audit JSON contract is closed to unknown fields.
- `verified` requires an empty mismatch list; `drifted` requires at least one supported mismatch code.

## Cumulative guarantees

Home Center 0.22 execution admission/evidence, 0.23 explicit durable
compare-and-swap authorization and 0.24 verification/pre-apply audit guarantees
remain cumulative. Completion evidence does not authorize another transition,
change external publication or mutate desired/service state.

The 0.25 branch remains a development candidate until its complete acceptance
and release gates pass.
