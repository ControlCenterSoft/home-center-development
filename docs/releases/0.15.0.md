# Home Center 0.15.0

Home Center 0.15.0 — инфраструктурно-независимый релиз с переносимым runtime и базовыми безопасными моделями планирования.

В состав версии входят:

- типизированная read-only инвентаризация инфраструктуры;
- детерминированное обнаружение узлов и агрегация health-состояния;
- безопасный preflight для maintenance/drain;
- deployment profiles, не привязанные к конкретной топологии;
- согласованная идентичность версии `0.15.0` в package/runtime;
- versioned JSON contracts и инфраструктурно-независимые границы конфигурации.

Версия не предполагает жёстко заданных имён узлов, адресов, доменов или другой операторской топологии. Наличие планирующих контрактов не является разрешением на произвольное изменение пользовательской инфраструктуры.
