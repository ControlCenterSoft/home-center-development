# Home Center 0.46.0

Status: development candidate.

Home Center 0.46 introduces the first product-level user-interface boundary between the mobile-first **«Уютный»** mode and the professional **«Полный»** mode without creating a second product or execution path.

## Interface modes

The web shell now exposes an explicit two-mode switch:

- **«Уютный»** is the default presentation for ordinary home use;
- **«Полный»** preserves the infrastructure-oriented view;
- the selected mode is persisted in browser-local UI state and restored on the next opening;
- switching modes is presentation-only and does not mutate Home Center Desired State, permissions, infrastructure or provider state.

## «Уютный» shell

The new mobile-first shell presents a simple «Домой» summary based on the existing infrastructure read model:

- overall home state;
- number of detected servers;
- number of available capabilities;
- understandable degraded/offline messaging with a direct path to the full interface for diagnostics.

This release intentionally does not claim the complete household navigation model. The full «Домой» / «Семья» / «Мой дом» menu boundary is assigned to 0.47.0.

## Compatibility and safety

- Existing full-interface infrastructure rendering remains available.
- No new infrastructure mutation path is introduced.
- No authorization, RBAC, audit, Desired/Actual State or recovery boundary is bypassed.
- External publication remains unchanged and disabled unless explicitly enabled by existing product configuration.

## Release identity

Release identity is `0.46.0` across `VERSION`, Python package metadata and runtime package metadata.

The candidate remains development-only until its complete acceptance and qualification gates pass.
