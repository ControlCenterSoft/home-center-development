# Home Center 0.46.0

Status: source package ready for qualification.

## Scope

Home Center 0.46.0 adds deterministic aggregate compatibility evidence for a
module that depends on multiple Home Services.

`home-center.module-home-service-contract-multi-compatibility-binding.v1`
binds one exact `mhsmr-*` multi-service requirement set to the exact
per-service `mhsrb-*` and `mhscb-*` compatibility identities produced from one
module admission binding and the required Home Service profiles.

The aggregate is `compatible` only when every required service dependency is
compatible. Missing, extra or duplicate service profiles, tampered requirement
evidence, invalid admission evidence and any per-service compatibility failure
are rejected or represented fail-closed. Service order does not affect the
aggregate identity.

## Safety boundary

The contract is evidence only. Admission, installation, execution, production
mutation and external publication authority remain false.

The implementation is topology-neutral and infrastructure-neutral. It adds no
Jobs/Operations behavior, Cluster/HA orchestration, placement semantics or
release-promotion logic. Authentication policy is unchanged.

No persistent-state migration is required.

## Qualification boundary

Runner-free source preparation includes the runtime contract, closed JSON
Schema and targeted unit/contract tests. Repository-wide qualification,
security/privacy evidence and release promotion remain the responsibility of
HC Release Engine A/B.
