# Home Center 0.58.0 — development notes

Status: **development only**. This document does not declare RC or Stable readiness.

Home Center 0.58 extends the qualified 0.57 enrollment-execution boundary with fail-closed
post-condition verification, explicit safe de-enrollment and bounded failed-enrollment cleanup.

Implemented in the current development slice:

- closed Draft 2020-12 schemas for enrollment verification request/read-back/evidence/receipt;
- exact enrollment verification binding to plan/provider operation/device/member/execution generation;
- bounded freshness checks and content-addressed verification evidence;
- `managed=true` authorization only after a successful provider read-back verification;
- deterministic de-enrollment plan bound to successful verification evidence and current Household
  snapshot/resource-version/generation;
- separate de-enrollment confirmation before provider mutation;
- explicit provider read-back after de-enrollment; only fresh exact-bound `unmanaged`/`absent`
  evidence can authorize the local managed-state transition;
- no automatic provider retry after unknown/ambiguous outcomes;
- failed-enrollment cleanup plan that permits only bounded transient cleanup after provider read-back;
- provider `managed` during cleanup blocks local cleanup and requires explicit de-enrollment;
- secret values, policy mutation, device-record removal, infrastructure mutation and external
  publication remain outside these contracts.

Not implemented or claimed here:

- concrete production provider verifier/adapter or provider qualification;
- production API/runtime durable verification/de-enrollment job wiring;
- durable Household managed-state writer integration;
- 0.58 release packaging, backup membership, install/upgrade/rollback qualification;
- real target-node and multi-node HA/restart acceptance;
- RC/Public Stable promotion;
- commercial/legal clearance.

Public Stable remains 0.56.0 until the authoritative release gates are closed. The 0.57 release
candidate path remains separate and is not re-qualified by this 0.58 development work.
