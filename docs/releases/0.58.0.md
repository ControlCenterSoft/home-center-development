# Home Center 0.58.0 — development notes

Status: **development only**. This document does not declare RC or Stable readiness.

Current 0.58 work begins with a provider-neutral post-condition verification contract stacked on the
0.57 enrollment-execution candidate. The contract separates provider command acceptance from actual
managed-device state and preserves fail-closed authority boundaries.

Implemented in this slice:

- closed Draft 2020-12 schemas for verification request, provider read-back result, evidence and
  verification receipt;
- exact binding to plan/provider operation/device/member/execution generation;
- bounded freshness inputs and provider-observation states;
- content-addressed verification evidence;
- managed-state authorization only after successful verification;
- rejected verification requires cleanup and cannot authorize policy, infrastructure or external
  publication.

Not implemented or claimed here:

- concrete provider verifier;
- production runtime integration or durable verification job;
- de-enrollment and automated cleanup/recovery;
- provider qualification;
- 0.58 release packaging, install/upgrade qualification, RC or Public Stable promotion;
- commercial/legal clearance.

Home Center Public Stable remains independent of this development slice until all authoritative
release gates are closed.
