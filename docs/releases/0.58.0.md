# Home Center 0.58.0

**Статус:** разработка; первый bounded slice, не Release Candidate и не Public Stable.

## Цель релиза

0.58.0 продолжает границу 0.57.0 после принятия команды подключения провайдером. Новый слой должен отдельно доказать фактический post-condition подключения и только после точной проверки разрешить Home Center изменить локальное Household-состояние устройства с `managed=false` на `managed=true`.

## Реализованный первый slice

- введён отдельный deterministic verification plan, привязанный к exact execution plan/job, provider operation, устройству, члену семьи и текущему Household snapshot;
- provider adapter получает только read/verify request и **не получает полномочий** изменять Household state, применять политики, менять инфраструктуру или публиковать сервисы;
- provider result принимается только при точном совпадении verification id, provider operation и device id;
- provider result обязан доказать `enrollment_completed=true` и `post_condition_verified=true`, но обязан оставить `managed_state_change_authorized=false`;
- Home Center выводит разрешение на managed-state transition только после собственной fail-closed проверки всех связей;
- stale Household snapshot, уже managed устройство, подмена provider operation и попытка провайдера присвоить себе mutation authority блокируются;
- успешный переход создаёт новый Household snapshot/commit и меняет только поле целевого устройства `managed` на `true`;
- применение политик, инфраструктурные изменения и external publication остаются запрещены.

## Что намеренно не входит в этот slice

- runtime/API orchestration provider verification;
- регистрация конкретного provider adapter;
- автоматическое применение MDM/сетевых/файловых политик после managed transition;
- любые действия за границей релиза 0.58.

Следующие изменения 0.58 должны встроить этот доменный контракт в durable runtime с explicit confirmation, Audit/Job evidence, crash/replay recovery и qualification конкретного provider adapter. До этого код является подготовленной безопасной границей, а не заявлением о готовности managed enrollment к эксплуатации.
