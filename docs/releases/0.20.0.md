# Home Center 0.20.0

Home Center 0.20 continues the cumulative home-service lifecycle introduced
in 0.19. The release adds typed operation plans for install, configure, health,
update, backup, restore and remove.

Every plan is bound to the exact instance generation and resource version and
has a stable idempotency identity. Configuration uses references to protected
secrets; operation contracts neither accept nor expose secret values.

Backup/restore support follows the service profile. Restore requires an
explicit recovery point, update includes backup where supported, and removal
disables external publication before deleting the service.

Plans remain non-authoritative: approval, a durable job and audit are required.
No operation plan executes a command or enables production mutation.
