# Home Center 0.57 — release-evidence tooling qualification

This document binds the stacked 0.57 release-evidence tooling slice to an exact hosted qualification pass before integration into the release-candidate line.

The slice adds machine-verifiable evaluators and closed schemas for the remaining external release evidence: single real target-node acceptance for the bounded `single-node-core` technical Stable profile, full real-environment/multi-node HA acceptance for profiles that claim HA, production-capable provider-adapter qualification, and bounded commercial-release disposition. It does not create or approve legal documents, fabricate real-environment/provider results, grant publication authority, or weaken existing fail-closed release gates.

Target-node evidence is not accepted as an opaque content-addressed file pair. The local target-node evaluator additionally requires closed `home-center.target-node-environment.v1` and `home-center.target-node-execution-transcript.v1` documents. Their node, source release, exact candidate version/revision/artifact, service-readiness observations and rollback identity must agree with the target-node manifest. Arbitrary text, cross-node/cross-candidate evidence, source identity drift and health/rollback claims without matching structured observations fail closed.

Hosted qualification must cover the exact current source head and preserve the existing Home Center boundaries: full unit/contract suite on the supported Python matrix, schema checks for all added release contracts, reproducible artifact checks, public-repository privacy boundary, infrastructure neutrality and CodeQL security gate where applicable.

A hosted PASS only validates the evidence tooling itself. Real target, HA, provider and commercial/legal facts remain external evidence inputs and must stay bound to the exact 0.57 candidate artifact/revision before the corresponding Stable/capability/commercial decision. The bounded `single-node-core` profile may omit HA/provider/commercial claims, but it must never infer or fabricate the remaining real target-node evidence.
