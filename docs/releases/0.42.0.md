# Home Center 0.42.0

Статус: source package подготовлен к qualification.

## Состав версии

Home Center 0.42.0 добавляет канонический versioned requirement-set contract для revisions Home Service/API, требуемых модулем.

`home-center.module-home-service-contract-requirement-set.v1` получает детерминированную identity `mhscr-*`. Identity связывает версию Home Center, module identity/version, target Home Service identity и канонический упорядоченный набор required revisioned contracts.

Это отделяет точную identity требований от более широкого module manifest и Home Service compatibility binding. Последующий binding может доказать, какой именно requirement set был проверен, и трактовать requirement-only drift как stale без ложного допущения, что неизменный manifest artifact является достаточным evidence.

Malformed, duplicate, empty, noncanonical или tampered serialized requirements отклоняются fail-closed.

## Граница безопасности

Requirement-set evidence носит только описательный характер и не разрешает admission, installation, execution, production mutation или external publication. Контракт topology-neutral и infrastructure-neutral и не создаёт отдельный mutation/release path. Миграция постоянного состояния не требуется.

## Проверка релиза

Qualification должен подтвердить runtime contract, closed JSON Schema, deterministic identity, targeted unit/contract behavior, security/privacy boundary и release identity. Source package не считается Public Stable до официального завершения release cycle.
