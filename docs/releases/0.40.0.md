# Home Center 0.40.0

Статус: source package подготовлен к qualification.

## Состав версии

Home Center 0.40.0 добавляет evidence-only compatibility binding между точным module contract/admission decision и существующим Home Service profile.

Новый контракт `home-center.module-home-service-contract-binding.v1` фиксирует canonical `mcab-*` identity, версии Home Center/модуля, точную SHA-256 identity Home Service profile и versioned service capability contracts, требуемые module integration.

Binding имеет статус `compatible` только когда module admission совместим и каждый запрошенный service contract предоставляется выбранным Home Service profile. Missing/unsupported revisions дают детерминированный `blocked`. Malformed, non-canonical, authority-bearing или tampered module binding evidence отклоняется fail-closed.

`home-center.home-service-catalog.v1` остаётся source of truth; эта версия не дублирует и не заменяет каталог Home Service.

## Граница безопасности

Binding является только compatibility evidence и не разрешает admission, installation, execution, production mutation или external publication. Контракт не содержит node placement или provider-specific semantics и применим к single-node и multi-node/HA. Миграция постоянного состояния не требуется.

## Проверка релиза

Qualification должен подтвердить runtime contract, closed JSON Schema, deterministic evidence identity, targeted unit/contract behavior, security/privacy boundary и release identity. Source package не считается Public Stable до официального завершения release cycle.
