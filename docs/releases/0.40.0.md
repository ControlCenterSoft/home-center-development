# Home Center 0.40.0

Status: source package ready for qualification.

## Scope

Home Center 0.40.0 adds an evidence-only compatibility binding between an
exact module contract/admission decision and an existing Home Service profile.

The new `home-center.module-home-service-contract-binding.v1` contract records
the canonical `mcab-*` identity, Home Center/module version, an exact SHA-256
identity of the Home Service profile, and the versioned service capability
contracts required by the module integration.

A binding is `compatible` only when the module admission is compatible and
every requested service contract is provided by the selected Home Service
profile. Missing or unsupported service contract revisions produce a
deterministic `blocked` result. Malformed, non-canonical, authority-bearing or
tampered module binding evidence is rejected fail-closed.

The existing `home-center.home-service-catalog.v1` profile contract remains the
source of truth. This package does not duplicate or replace the Home Service
catalog.

## Safety boundary

The binding is compatibility evidence only. It does not authorize module
admission, installation, execution, production mutation or external
publication.

The contract contains no node placement or infrastructure-provider semantics
and is valid for single-node and HA deployments. It does not add
Jobs/Operations behavior, Cluster/HA orchestration or release-promotion logic.

No persistent-state migration is required.

## Qualification boundary

Runner-free source preparation includes the runtime contract, closed JSON
Schema, deterministic evidence identity, targeted unit/contract tests and
version metadata. GitHub Actions qualification, security/privacy evidence,
release promotion and publication remain responsibilities of the dedicated
Home Center release engines.
