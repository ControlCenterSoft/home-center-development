# Home Center 0.55.0

Status: source package prepared for qualification.

## Область релиза

Home Center 0.55.0 добавляет канонический read-only индекс фактических module/Home Service compatibility states. Релиз не меняет состояние модулей или сервисов и не предоставляет право на установку, выполнение, production mutation либо external publication.

Индекс строится только из уже валидированных контрактов `home-center.module-home-service-compatibility-state.v1`. Каждый элемент сохраняет собственную точную evidence identity, а индекс формирует единый детерминированный snapshot для последующего использования Market и интерфейсом «Мой дом».

## Каноническая идентичность

Контракт индекса: `home-center.module-home-service-compatibility-state-index.v1`.

Индекс содержит:

- точную `home_center_version`;
- детерминированно отсортированный список module compatibility states;
- `module_count`, `compatible_count`, `blocked_count`, `stale_count`;
- агрегированный `summary_status`;
- content-derived `resource_version`;
- `index_id`, производный от `resource_version`;
- strong `ETag`, также производный от того же content digest.

Порядок входных state не влияет на identity. Два state одного `module_id` в одном snapshot считаются неоднозначным состоянием и отклоняются fail-closed. Смешивание state от разных Home Center versions запрещено.

## Fail-closed приоритет статуса

Агрегированный статус имеет строгий порядок безопасности:

1. `stale`, если хотя бы один member state stale;
2. `blocked`, если stale отсутствуют, но хотя бы один state blocked;
3. `compatible`, если все присутствующие state current и compatible;
4. `empty`, если модулей в индексе нет.

`empty` не подменяется статусом `compatible`, поэтому отсутствие evidence не отображается как подтверждённая совместимость.

## Граница безопасности

Индекс и каждый входящий state остаются non-authorizing evidence. На уровне индекса неизменно фиксируются:

- `admission_authorized=false`;
- `installation_authorized=false`;
- `execution_authorized=false`;
- `production_mutation_enabled=false`;
- `external_publication_authorized=false`.

Изменение любого из этих флагов, identity, счётчиков, порядка элементов или вложенного state приводит к отклонению валидации. Индекс не выполняет installation/update/remove, не запускает Home Service lifecycle и не меняет Desired/Actual State.

## Contract и artifact boundary

Добавлен закрытый JSON Schema:

`contracts/modules/module-home-service-compatibility-state-index.v1.schema.json`.

Schema запрещает неизвестные поля, ограничивает размер индекса и фиксирует authority flags в `false`.

Release artifact qualification должна требовать runtime-модуль:

`home_center/module_home_service_compatibility_state_index.py`.

## Qualification boundary

Qualification 0.55 должна подтвердить как минимум:

- детерминированность identity и strong ETag;
- независимость identity от порядка входного списка;
- каноническую сортировку по `module_id`;
- запрет duplicate module identity;
- запрет смешивания Home Center versions;
- приоритет `stale` над `blocked` и `compatible`;
- приоритет `blocked` над `compatible` при отсутствии stale;
- отдельный `empty`, а не ложный `compatible`, для пустого набора;
- точность derived counts;
- отказ при tamper `resource_version`, `ETag`, counts, member state или authority flags;
- закрытость JSON Schema и отсутствие mutation authority.

Persistent state migration не требуется: 0.55 вводит детерминированную read-only агрегацию уже существующего compatibility evidence.
