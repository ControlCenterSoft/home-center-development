# Home Center 0.60.0

Status: source development; not Release Candidate and not Public Stable.

## Назначение

0.60.0 развивает родительскую Internet/DNS/Proxy policy поверх официального Home Center 0.59.0 Public Stable. Текущий source scope предназначен только для child policy и сохраняет общий fail-closed путь Home Center: verified base → plan → explicit confirm → protected Desired State → typed provider boundary → Actual State read-back → verification.

## Уже интегрированная source-граница

- детерминированные allow/deny domains и categories;
- точная привязка к `rule_source_id`, версии и SHA-256 источника правил;
- расписания, daily/weekly quotas, continuous-session limits, breaks, grace и bonus;
- default deny и объяснимый результат ALLOW/DENY;
- строгая storage/transport reconstruction против exact verified 0.59 child-policy base;
- parent-only plan и отдельное explicit confirm;
- durable Job/Audit и protected parental Desired State с exact Household/base/evidence/generation binding;
- idempotent replay и fail-closed rejection stale/tampered/competing state;
- backup/restore qualification для parental Desired State;
- typed provider-neutral DNS/proxy adapter capabilities, apply/readback/observation/rollback contracts;
- read-only post-condition verifier с freshness и exact Desired State/policy/provider-operation binding;
- reproducible wheel qualification обязана содержать все интегрированные 0.60 runtime modules.

## Safety boundary

Сохранение parental Desired State не означает, что DNS/proxy policy применена. Provider command acceptance также не является enforcement success. До отдельного подтверждённого post-condition transition сохраняются:

- `enforcement_verified=false`;
- `reconciliation_required=true`;
- `dns_policy_applied=false`;
- `proxy_policy_applied=false`;
- infrastructure mutation и external publication не разрешаются автоматически.

Concrete production adapter не регистрируется текущим source scope. Автоматический retry неоднозначного provider outcome, universal provider execution, multi-node HA/automatic failover и external publication не заявляются.

## Qualification status

Интегрированные 0.60 source slices прошли обычные exact-head Home Center CI, Python 3.12/3.13/3.14, reproducible artifact qualification, Public repository privacy boundary, Infrastructure neutrality и CodeQL security-extended checks. Эти проверки подтверждают только соответствующий exact source; они не создают Release Candidate или Public Stable authority.

## Commercial / legal boundary

0.60 source scope не добавляет новую стороннюю runtime dependency или новый bundled provider. Техническая qualification не является коммерческим запуском. Commercial launch clearance, support/licensing claims и любые provider-specific redistribution obligations остаются отдельным evidence track, если соответствующий concrete provider будет добавлен.

## Оставшиеся gates до Release Candidate

До Release Candidate должны быть закрыты только фактически реализованные и заявляемые capabilities. Для текущего 0.60 направления остаются как минимум:

1. production execution/orchestration path только через квалифицированный concrete DNS/proxy adapter либо явное ограничение итогового Stable profile без такой capability;
2. exact post-condition state transition, если релиз будет заявлять фактическое применение policy;
3. install/upgrade/rollback qualification exact 0.60 candidate от Public Stable 0.59.0;
4. финальные security/privacy, artifact, release metadata/checksum/provenance gates для immutable candidate identity;
5. отдельная Public Stable promotion.

Текущий официальный Public Stable остаётся Home Center 0.59.0 до завершения отдельного 0.60 release cycle.
