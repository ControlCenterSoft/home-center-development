# Home Center 0.61.2

Status: official release.

Release profile: `single-node-core`.

## Назначение

Home Center 0.61.2 — второй корректирующий patch-релиз линии VPN egress policy после опубликованного `v0.61.1`. Он сохраняет функциональную границу 0.61 и завершает fail-closed исправление split routing на всех внутренних и пользовательских evidence-проекциях без переписывания immutable `v0.61.0` или `v0.61.1`.

`v0.61.1` уже опубликован как отдельная immutable source identity. После дополнительного runner-free аудита обнаружено, что его исправленный core route decision мог выдавать новый безопасный `DENY / split_route_direct_not_authorized`, но Cozy/Full projection не принимала этот reason, а release qualification была привязана к устаревшему baseline 0.60.0. Поэтому 0.61.2 получает новую exact identity и не переиспользует release evidence 0.61.1.

## Security correction

- split-route direct egress разрешается только при явном `fallback_mode=direct` и выключенном kill switch;
- при `kill_switch=true` или `fallback_mode=deny` non-matching split-route domain завершается `DENY / split_route_direct_not_authorized`;
- strict storage/transport reconstruction и closed JSON Schema запрещают противоречивые пары `route/reason`;
- Cozy/Full projection принимает fail-closed deny reason и показывает безопасную блокировку вместо invalid/unknown состояния;
- transport-neutral API projection дополнительно отклоняет противоречивые in-process решения, например `DIRECT + split_route_direct_not_authorized` или `DENY + split_route_direct`;
- parental `DENY` сохраняет абсолютный приоритет.

## Сохраняемая 0.61 boundary

- provider/version/location evidence и deterministic selection;
- full/split routing decision surface;
- explicit DNS strategy;
- kill-switch/fallback semantics;
- exact binding к Household/parental policy;
- Cozy/Full evidence projections;
- отсутствие concrete provider/network mutation authority в bounded Stable profile.

Provider selection is not VPN activation. Concrete production VPN adapter execution, network/firewall/routing mutation, Multi-node HA / automatic failover и commercial launch clearance не заявляются без отдельного qualified evidence и остаются fail-closed/unclaimed.

## Install / upgrade / rollback

Обязательная qualification выполняется на exact release identity без source rewrite. Базовый supported patch path для Public Stable promotion — `0.61.0 → 0.61.2` с install/upgrade, readiness/restart, сохранностью state/credentials и rollback обратно к 0.61.0. Evidence от 0.61.1 не переносится автоматически на новую identity.

## Release evidence

Public Stable promotion допускается только после exact-head Python 3.12/3.13/3.14 CI, reproducible artifact qualification, CodeQL security-extended fail-closed gate, privacy/infrastructure-neutrality checks и полного checksum/provenance/manifest/SBOM release set. False Success остаётся release blocker.
