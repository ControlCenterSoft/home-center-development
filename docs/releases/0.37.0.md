# Home Center 0.37.0

Status: official release.

## Module contract compatibility profile

Home Center publishes a canonical, version-bound compatibility profile for the
module contracts understood by the admission boundary. The profile has a
deterministic `mccp-*` identity and enumerates supported revisions for the
manifest, admission, revalidation, runtime-snapshot, candidate-set and
compatibility-policy contract families.

A pre-admission negotiation decision (`mcnd-*`) checks the exact contract
revisions requested by a module-facing caller. The negotiation is fail-closed:
unknown contract families, malformed schema identifiers and incomplete
mandatory requests are rejected, while unsupported revisions produce an
explicit `unsupported-contract` result.

The current admission implementation accepts
`home-center.module-manifest.v2`; the legacy v1 schema remains a repository
artifact but is intentionally not advertised as supported by the runtime
admission profile.

Both the compatibility profile and negotiation decision are evidence only.
They never authorize admission, installation, execution, production mutation
or external publication. Existing artifact verification, provenance
validation and module compatibility-policy boundaries remain unchanged.

The contract is topology-neutral and does not encode single-node or HA
placement assumptions. No persistent-state migration is required.

## Installation and update

The official GitHub Release includes the Linux amd64 deployment archive and its
SHA256 checksum. Verify the checksum before installation or update and retain
the currently working version for rollback until post-update health checks are
complete.

Existing user passwords, secrets and local configuration must be preserved by
the update path; this release does not require resetting authentication data.
