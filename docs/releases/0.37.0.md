# Home Center 0.37.0

Status: source-development package ready for qualification.

## Module contract compatibility profile

Home Center now publishes a canonical, version-bound compatibility profile for
the module contracts understood by the admission boundary. The profile has a
deterministic `mccp-*` identity and enumerates supported revisions for the
manifest, admission, revalidation, runtime-snapshot, candidate-set and
compatibility-policy contract families.

A new pre-admission negotiation decision (`mcnd-*`) checks the exact contract
revisions requested by a module-facing caller. The negotiation is fail-closed:
unknown contract families, malformed schema identifiers and incomplete
mandatory requests are rejected, while unsupported revisions produce an
explicit `unsupported-contract` result.

The current admission implementation accepts
`home-center.module-manifest.v2`; the legacy v1 schema remains a repository
artifact but is intentionally not advertised as supported by the runtime
admission profile.

Both profile and negotiation decision are evidence only. They never authorize
admission, installation, execution, production mutation or external
publication. Existing artifact verification, provenance validation, module
compatibility policy and qualification boundaries remain unchanged.

The contract is topology-neutral and does not encode single-node or HA
placement assumptions. No persistent-state migration is required.

## Qualification boundary

This source package includes targeted unit/contract tests and closed JSON
schemas. Repository-wide CI, security evidence, release promotion and
publication remain responsibilities of the qualification/release engines.
