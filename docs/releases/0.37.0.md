# Home Center 0.37.0

Статус: source package подготовлен к qualification.

## Профиль совместимости контрактов модулей

Home Center 0.37.0 вводит канонический version-bound профиль совместимости для module contracts, понимаемых границей admission. Профиль имеет детерминированную identity `mccp-*` и перечисляет поддерживаемые revisions для семейств manifest, admission, revalidation, runtime-snapshot, candidate-set и compatibility-policy.

Новое pre-admission решение negotiation (`mcnd-*`) проверяет точные contract revisions, запрошенные module-facing caller. Negotiation работает fail-closed: неизвестные семейства контрактов, malformed schema identifiers и неполные обязательные запросы отклоняются, а неподдерживаемые revisions дают явный результат `unsupported-contract`.

Текущая admission-реализация принимает `home-center.module-manifest.v2`; legacy v1 schema сохраняется как исторический repository artifact, но намеренно не объявляется поддерживаемой runtime admission profile.

Profile и negotiation decision являются только evidence. Они не разрешают admission, installation, execution, production mutation или external publication. Существующие artifact/provenance verification и module compatibility boundaries не изменяются.

Контракт topology-neutral и не содержит single-node/HA placement assumptions. Миграция постоянного состояния не требуется.

## Проверка релиза

Source package содержит targeted unit/contract tests и закрытые JSON schemas. Публикация версии допускается только после полного набора обязательных qualification, security/privacy и release checks; подготовительный package сам по себе не является опубликованным Stable и не предоставляет runtime-полномочий.
