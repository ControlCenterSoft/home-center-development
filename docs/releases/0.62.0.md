# Home Center 0.62.0

Status: source foundation prepared; not Release Candidate and not Public Stable.

## Scope prepared in this slice

0.62 begins the Roadmap role-driven identity/account provisioning line on top of the Policy Composer foundation already present in Stable 0.59.

Prepared source boundaries:

- typed local/directory identity-provider capability evidence;
- exact Household snapshot/member/role/policy/provider binding;
- deterministic content-addressed provisioning plan;
- explicit local vs portable home-directory and profile modes;
- strict reconstruction that rejects unknown fields, evidence tampering and authority escalation;
- Cozy and Full plan projections that do not claim an account was created;
- explicit isolation of the existing local emergency administrator.

## Safety boundary

This source slice does **not**:

- create a local or directory account;
- create or modify a directory object;
- set, return or authorize password/token/credential values;
- create a home directory or portable profile;
- grant operating-system, sudo/root, directory-admin or similar privileges;
- change the emergency local administrator identity;
- execute a provider or mutate infrastructure;
- publish any service externally.

Reserved emergency account names `admin`, `administrator` and `root` are rejected by the planning contract. Portable home/profile requests fail closed unless the exact provider evidence explicitly advertises support.

## Required before execution work

Any later execution boundary remains separate and must require explicit confirmation, exact-state revalidation, a typed provider adapter, secret-reference-only credential handling, account-absence/name-conflict preflight, durable Job/Audit evidence, read-back and post-condition verification before success can be reported.

Current Public Stable remains 0.59.0. This preparation does not change `VERSION`, create a release candidate, claim provider/HA support or grant commercial-launch clearance.
