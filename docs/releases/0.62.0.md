# Home Center 0.62.0

Status: official release.

Release profile: `single-node-core`.

## Пользовательский результат

Home Center 0.62.0 завершает безопасную product boundary для role-driven identity/account provisioning. Родительский/административный пользователь может подготовить точный план создания локальной или directory identity через квалифицированный provider, проверить server-side preflight, явно подтвердить provider execution и только после подтверждённого read-back отдельно связать проверенную identity с точным Household member.

Релиз продолжает официальный Public Stable 0.61.2 и наследует его fail-closed VPN split-routing security correction.

## Что входит

- typed local/directory identity-provider capability и exact Household/member/role/policy/provider binding;
- content-addressed provisioning plan с local/portable home/profile modes и изоляцией emergency local admin;
- qualification-bound provider registry: generic self-declared adapter не может попасть в production runtime;
- exact provider qualification contract с real-provider/real-target evidence, artifact/transcript/environment/recovery digests и запретом переноса evidence между кандидатами;
- server-authoritative API `plan → preflight → execute`: client выбирает только уже зарегистрированный qualified provider ID и не может прислать provider capability, qualification evidence или account-preflight observation;
- fresh account-absence preflight повторно читается server-side непосредственно перед execution;
- execution принимает только bounded `secret://` references, создаёт durable Job до side effect, вызывает provider mutation не более одного раза и требует отдельный read-back/post-condition verification;
- provider acceptance не является успехом; ambiguous outcome остаётся fail-closed и не получает автоматический retry;
- отдельный confirmed `/bind` после verified execution читает точный persisted receipt по durable execution Job ID, повторно проверяет Household authority/snapshot, выполняет CAS/read-back Home Center binding и никогда не reinvoke-ит provider;
- backup/restore сохраняет durable verified execution/binding evidence;
- wheel и node deployment artifact включают runtime/API/qualification/binding modules и закрытые JSON contracts.

## Security boundary

0.62.0 не принимает password/token/credential values через product API, не выдаёт generic shell, sudo/root/directory-admin authority, не изменяет emergency `admin`, не выполняет unrelated account mutation и не публикует сервисы наружу. Зарезервированные имена `admin`, `administrator` и `root` отклоняются planning boundary.

Provider-specific execution остаётся **fail-closed**, пока конкретный adapter не зарегистрирован через exact qualification evidence. В базовый release profile не встроен автоматически активируемый universal provider. Отсутствие qualified provider означает отказ операции до side effect, а не скрытый fallback.

## Подтверждаемые и неподтверждаемые claims

Public Stable относится к самому Home Center 0.62.0 и его bounded single-node core. Он не означает автоматическую сертификацию каждого внешнего identity provider.

Не заявляются без отдельной qualification:

- universal concrete production identity-provider execution;
- portable home/profile для provider, который не подтвердил соответствующую capability;
- multi-node HA / automatic failover;
- commercial-launch clearance.

Эти ограничения не превращаются в ложный PASS: соответствующие возможности остаются disabled/fail-closed и не заявляются как поддерживаемые.

## Upgrade / rollback

Поддерживаемая текущая линия обновления для release qualification: **0.61.2 → 0.62.0 → 0.61.2**. Обновление обязано сохранять SQLite state, конфигурацию, пользовательские данные, установленный пароль администратора, sessions/Audit, systemd units и enabled/active state. Rollback должен восстанавливать предыдущую release identity и сохранённое состояние без provider reinvocation.

Release qualification обязана быть exact-head и включать Python 3.12/3.13/3.14, reproducible artifacts, JSON contracts, hosted install/upgrade/rollback, real-systemd health/rollback, CodeQL security-extended, public privacy boundary и infrastructure neutrality.
