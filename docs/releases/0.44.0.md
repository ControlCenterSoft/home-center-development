# Home Center 0.44.0

Status: source package ready for qualification.

## Scope

Home Center 0.44.0 adds exact-state revalidation for the canonical module
Home Service requirement binding introduced in 0.43.0.

`home-center.module-home-service-contract-requirement-binding-revalidation.v1`
gives each revalidation a deterministic `mhsrbr-*` identity. Revalidation
first reconstructs the original `mhsrb-*` from its original requirement set,
module contract/admission binding and Home Service profile. Any tampered or
inconsistent original evidence is rejected fail-closed.

The same binder is then applied independently to fresh requirement, admission
and Home Service evidence. The result is `current` only when the exact
requirement set, Home Service compatibility binding, Home Center version,
module identity/version, service identity, service-profile digest, required
contract revisions and compatibility status remain unchanged. Any drift makes
the evidence `stale`, including requirement-only, admission-only or
profile-only drift.

## Safety boundary

Revalidation evidence is descriptive only. It never authorizes admission,
installation, execution, production mutation or external publication.

The contract is topology-neutral and infrastructure-neutral. It adds no
Jobs/Operations behavior, Cluster/HA orchestration, placement semantics or
release-promotion logic. Existing authentication policy is unchanged.

No persistent-state migration is required.

## Qualification boundary

Runner-free source preparation includes the runtime contract, closed JSON
Schema and targeted unit/contract tests. Repository-wide qualification,
security/privacy evidence and release promotion remain the responsibility of
HC Release Engine A/B.
