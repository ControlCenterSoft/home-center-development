# Home Center 0.44.0

Статус: официальный source release; версия также опубликована в Public Stable.

## Состав релиза

Home Center 0.44.0 добавляет exact-state revalidation для канонической связи требований модуля с Home Service, введённой в 0.43.0.

`home-center.module-home-service-contract-requirement-binding-revalidation.v1` задаёт каждой проверке детерминированную identity `mhsrbr-*`. Revalidation сначала повторно строит исходный `mhsrb-*` из его requirement set, module contract/admission binding и профиля Home Service. Любое повреждённое или внутренне несогласованное исходное evidence отклоняется fail-closed.

Затем тот же binder независимо применяется к свежим requirement, admission и Home Service evidence. Результат считается `current` только когда точный requirement set, Home Service compatibility binding, версия Home Center, identity/версия модуля, identity сервиса, digest профиля сервиса, требуемые revisions контрактов и compatibility status не изменились. Любой drift переводит evidence в `stale`, включая drift только требований, только admission или только профиля.

## Граница безопасности

Revalidation evidence носит только описательный характер. Оно никогда не разрешает admission, установку, execution, production mutation или external publication.

Контракт topology-neutral и infrastructure-neutral. Он не добавляет Jobs/Operations behavior, Cluster/HA orchestration, placement semantics или скрытый release-promotion path. Существующая политика аутентификации не меняется.

Миграция постоянного состояния не требуется.

## Проверка релиза

Точное release tree 0.44.0 прошло обязательные qualification gates, включая проверки контрактов, воспроизводимости артефактов, public-repository privacy boundary, infrastructure-neutrality и fail-closed commercial/legal compliance evidence до публикации. Публикация версии сама по себе не предоставляет production mutation authority; установка и активация выполняются только через штатный проверяемый update path.
