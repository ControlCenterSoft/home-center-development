# Home Center 0.18.0

Home Center 0.18.0 — накопительный переносимый релиз, развивающий authorization, certificate inventory и безопасное планирование remote access поверх возможностей предыдущих версий.

Граница 0.18 остаётся fail-closed и plan-only. Authorization использует ограниченную default-deny policy; планирование обновления сертификатов строится на наблюдаемых данных без включения секретного материала; reverse-proxy и direct publication требуют явного hostname, TLS, authentication и подтверждённой runtime readiness.

Контракты версии не предоставляют доступ к приватным ключам, не выполняют скрытое обнаружение внешних endpoint, не изменяют firewall/NAT и сами по себе не дают полномочий на production-выполнение. Доступность конкретной возможности определяется установленной версией, конфигурацией и поддерживаемым provider profile.
