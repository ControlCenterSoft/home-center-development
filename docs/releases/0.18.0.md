# Home Center 0.18.0

Cumulative portable authorization/certificate/remote-access release: verified stable runtime + 0.15–0.17 + provider-neutral RBAC, secret-free certificate inventory and runtime-readiness-driven remote access planning.

The 0.18 boundary is fail-closed and plan-only. Authorization requires a bounded, default-deny policy; certificate renewal emits deterministic plans from non-secret observations; public reverse-proxy and direct publication require an explicit hostname, TLS, authentication and matching runtime readiness. No contract grants private-key handling, endpoint discovery, firewall/NAT changes or production execution authority.

Release finalization requires ancestry from the exact qualified 0.17 release, full source compilation, JSON contract parsing, unit and module-import tests, infrastructure-neutrality scanning, and two clean-tree wheel builds with identical SHA-256 digests. A 0.18 tag or deployment must not precede that cumulative qualification.
