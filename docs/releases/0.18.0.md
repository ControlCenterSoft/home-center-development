# Home Center 0.18.0

Cumulative infrastructure-neutral release integration for authorization, certificates, and remote access planning.

- RBAC supports provider-neutral local and directory-backed subject references with default-deny semantics.
- Certificate inventory is secret-free and plans renewals from runtime inventory/readiness data.
- Remote Access Planner consumes runtime hostname/TLS/DNS/network/authentication readiness and never embeds environment endpoints.
- 0.18.0 includes the complete cumulative 0.15–0.17 portable development stack.
