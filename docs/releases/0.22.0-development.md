# Home Center 0.22.0 development package

Home Center 0.22.0 continues the home-service lifecycle from approved execution admission toward a safe, observable worker handoff.

Initial parallel workstreams:

- deterministic worker claim bound to the target node;
- compare-and-swap revalidation immediately before execution;
- verified execution-result records;
- explicit separation between result evidence and durable state transition;
- fail-closed job-state and generation/resource-version checks;
- production mutation remains disabled until a dedicated execution gate is qualified.

Implemented transition boundary:

- immutable execution-result evidence cannot update durable instance state;
- a typed decision checks verified success and the complete admission, claim,
  worker, node, job, instance and compare-and-swap binding;
- every mismatch produces a closed, machine-readable rejection code;
- an allowed decision produces a deterministic, idempotent commit envelope;
- the commit envelope records the expected and next generation/resource version,
  but remains uncommitted and cannot mutate production state.

This file marks the start of the 0.22 development cycle; it is not a production release declaration.
