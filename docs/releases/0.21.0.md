# Home Center 0.21.0

Home Center 0.21 closes the state and admission boundary for the home-service
lifecycle introduced in 0.19–0.20.

Service instances now have durable SQLite state with a versioned migration,
exact generation/resource-version compare-and-swap, restart persistence, and
atomic idempotent transitions. Persisted instance records remain secret-free.

Execution admission binds the immutable operation-plan hash to approval
evidence, a durable preflight job, audit correlation, and the exact instance
snapshot. A worker claim must revalidate those preconditions. The admission
record cannot directly execute a command and production mutation remains
disabled.

The release artifact is reproducibly built and contains both new runtime
modules. Publication of the tag does not deploy to production.
