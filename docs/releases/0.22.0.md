# Home Center 0.22.0

Home Center 0.22 establishes the observable worker handoff boundary for the
home-service lifecycle. A worker claim is deterministic, bound to the admitted
plan, target node, durable job and exact service-instance generation and
resource version.

Immediately before execution, a second compare-and-swap fence revalidates the
queued job, canonical admission digest, worker claim token digest and live
instance version. The revalidation record remains inert and cannot execute the
operation.

Execution results are immutable evidence records. They remain separate from a
durable service-state transition and cannot authorize that transition by
themselves. Claims and result evidence accept no secret values, cannot carry an
arbitrary command, and keep production mutation disabled.

A separate transition decision validates the entire admission, claim, evidence
and live-instance chain. Its compare-and-swap commit envelope is deterministic
and idempotent, but remains uncommitted and cannot mutate durable state. This
keeps result recording and state change as two explicit authorization domains.

The release artifact is reproducibly built and explicitly contains the worker
claim, execution revalidation, execution-result and state-transition runtime
modules. Publication does not deploy or enable production execution.
