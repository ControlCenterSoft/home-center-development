# Home Center 0.63.0

Status: source foundation prepared; not Release Candidate and not Public Stable.

## Scope

0.63 prepares bounded QR guest/device onboarding within the current development horizon after Public Stable 0.60.0.

Prepared source boundaries:

- parent-only immutable onboarding invitation;
- guest or exact-device subject binding;
- 60–1800 second TTL;
- single-use onboarding code with only SHA-256 persisted in durable invitation evidence;
- ephemeral QR payload explicitly classified as a short-lived onboarding code rather than an administrative credential;
- first-class expiration, revocation and consumed-state evaluation;
- deterministic redemption plan requiring a separate explicit confirmation;
- closed JSON contracts for invitation, QR payload and redemption plan.

## Safety boundary

QR presentation does not create an account, bind a device, grant parent/admin privileges, execute a provider, mutate infrastructure or publish a service externally. Revoked, expired, consumed or code-mismatched invitations fail closed.

The QR payload must never contain a long-lived administrative credential, emergency-admin secret, directory administrator password or persistent API token. The short-lived onboarding code is single-use and must not be persisted or logged as durable evidence.

## Required follow-up

A later mutation layer must atomically consume the invitation, revalidate current Household/device state, require explicit confirmation, write Audit evidence and verify the resulting guest/device state before reporting success. Restore/restart must not resurrect revoked, consumed or expired invitations.

No release identity is changed by this source preparation. Concrete provider/HA/commercial claims remain separate qualification boundaries.
