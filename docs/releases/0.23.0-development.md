# Home Center 0.23.0 development

This document establishes the version baseline for the next Home Center release.

## Baseline

- Release identity is `0.23.0` across package metadata and runtime version surfaces.
- Home Center 0.22.0 home-service safety and non-mutating execution guarantees remain cumulative requirements.
- Additional 0.23.0 capabilities must preserve the existing infrastructure-neutral product boundary and compatibility guarantees.

This is a development baseline, not the final 0.23.0 release note.
