# Home Center 0.50.0

Status: source package ready for qualification.

## Scope

Home Center 0.50.0 adds a deterministic read-only state projection for a
module's effective compatibility with its required Home Services.

The new `home-center.module-home-service-compatibility-state.v1` contract
combines one exact `mhsmcb-*` aggregate compatibility binding with its exact
`mhsmcbr-*` revalidation evidence. The projection exposes a canonical
`mhscs-*` state identity, content-derived `resource_version`, strong `etag`,
module identity, service set, blocked-service set, observed compatibility and
freshness.

A stale revalidation is projected as effective status `stale` even when the
freshly observed compatibility is `compatible`. This keeps stale evidence
fail-closed for API and UI consumers. Current evidence projects the observed
`compatible` or `blocked` status unchanged.

Serialized state is closed and canonical. It rejects unknown fields,
non-canonical service ordering, mismatched blocked-service/compatibility state,
unknown drift reasons, tampered resource identity or ETag, and any authority
flag set to true.

## Safety boundary

This is a read-only evidence projection. Admission, installation, execution,
production mutation and external publication authority remain false. No
Jobs/Operations behavior, Cluster/HA orchestration, placement semantics or
release-promotion logic is added. Authentication policy is unchanged, and the
contract is topology-neutral and infrastructure-neutral.

No persistent-state migration is required.
