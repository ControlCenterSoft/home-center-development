# Home Center 0.41.0

Status: official release.

## Scope

Home Center 0.41.0 adds exact-state revalidation for the
`home-center.module-home-service-contract-binding.v1` evidence introduced in
0.40.0.

The new
`home-center.module-home-service-contract-binding-revalidation.v1` contract
reconstructs the original `mhscb-*` binding from its original module admission
binding, Home Service profile and required service contracts before comparing
it with a freshly calculated binding.

A revalidation is `current` only when the exact module contract/admission
binding, Home Center version, module identity/version, Home Service profile
identity, required/provided/unsupported service contracts and resulting
compatibility status are unchanged. Any detected drift produces a deterministic
`stale` result.

Malformed or tampered original evidence is rejected fail-closed instead of
being reported as stale. Malformed fresh evidence is also rejected fail-closed.

## Safety boundary

Revalidation is evidence only. It does not authorize module admission,
installation, execution, production mutation or external publication.

The contract is topology-neutral and infrastructure-neutral. It adds no
Jobs/Operations behavior, Cluster/HA orchestration, placement semantics or
release-promotion logic. Existing authentication policy is unchanged.

No persistent-state migration is required.

## Verification

The release contains the runtime contract, closed JSON Schema, deterministic
evidence identity, targeted unit and contract tests, aligned version metadata,
reproducible package validation, infrastructure-neutrality checks and public
repository privacy checks.
