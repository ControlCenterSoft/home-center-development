# Home Center 0.41.0

Статус: source package подготовлен к qualification.

## Состав версии

Home Center 0.41.0 добавляет exact-state revalidation для `home-center.module-home-service-contract-binding.v1` из 0.40.0.

Контракт `home-center.module-home-service-contract-binding-revalidation.v1` восстанавливает исходный `mhscb-*` binding по исходному module admission binding, Home Service profile и required service contracts, после чего сравнивает его со свежим binding.

Revalidation имеет статус `current` только когда неизменны exact module contract/admission binding, версия Home Center, module identity/version, Home Service profile identity, required/provided/unsupported service contracts и итоговый compatibility status. Любой обнаруженный drift даёт детерминированный `stale`.

Malformed/tampered original evidence и malformed fresh evidence отклоняются fail-closed.

## Граница безопасности

Revalidation является только evidence и не разрешает module admission, installation, execution, production mutation или external publication. Контракт topology-neutral и infrastructure-neutral и не создаёт отдельный mutation/release path. Миграция постоянного состояния не требуется.

## Проверка релиза

Qualification должен подтвердить runtime contract, closed JSON Schema, deterministic evidence identity, targeted unit/contract behavior, security/privacy boundary и release identity. Подготовленный source package сам по себе не является Public Stable.
