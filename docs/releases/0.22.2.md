# Home Center 0.22.2

Home Center 0.22.2 supersedes 0.22.1 as the deployable web-interface hotfix for the 0.22 release line.

The built-in interface keeps the repaired canonical `/static/app.css` and `/static/app.js` routes, responsive mobile-first technical dashboard, same-origin authentication flow and mandatory first-login local administrator password change introduced by 0.22.1.

This patch also closes the rolling-upgrade compatibility gap detected by hardened cluster updaters. The deployment installer now explicitly recognizes `/etc/home-center/deployment-profile.json` as persistent node-local configuration: when that file exists it is validated as a regular JSON object and preserved in place. The signed deployment artifact contains an immutable installer core, and the compatibility wrapper verifies the artifact SHA-256 before extracting or executing that core.

The patch does not expand the 0.22 execution boundary or create a new production mutation path. Worker handoff evidence still cannot authorize that transition by itself. Existing state-database backup, node rollback, service-readiness, topology-neutrality and peer-first rolling-update safeguards remain in force.
