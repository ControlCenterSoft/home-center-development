# Home Center 0.39.0

Статус: source package подготовлен к qualification.

## Состав версии

Home Center 0.39.0 добавляет exact-state revalidation для `home-center.module-contract-admission-binding.v1`, введённого в 0.38.0.

Добавлены `home-center.module-contract-admission-binding-revalidation.v1` и детерминированная identity `mcabr-*`. Revalidation восстанавливает исходный `mcab-*` из exact compatibility profile, contract negotiation и module admission evidence, после чего сравнивает его со свежим evidence.

Binding считается `current` только когда исходное и свежее evidence описывают одно и то же точное contract/admission state. Изменение contract profile, negotiation decision, версии Home Center, выбранных contract revisions, module identity/version, manifest binding, verified artifact identity, admission decision или admission outcome переводит результат в `stale`.

Malformed или tampered original/fresh evidence отклоняется fail-closed и не представляется как обычный drift.

## Граница безопасности

Revalidation является только evidence. Она не разрешает module admission, installation, execution, production mutation или external publication.

Контракт не содержит topology placement semantics и совместим с single-node и multi-node/HA deployments. Он не добавляет скрытый execution или release-promotion path. Миграция постоянного состояния не требуется.

## Проверка релиза

Обязательный qualification должен подтвердить runtime contract, закрытую JSON Schema, deterministic evidence identity, targeted unit/contract behavior, security/privacy boundary и release identity. Source package сам по себе не является Public Stable.
