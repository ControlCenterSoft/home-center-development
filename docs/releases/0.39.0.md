# Home Center 0.39.0 — exact-state contract/admission binding revalidation

Status: official release.

## Scope

Home Center 0.39.0 adds exact-state revalidation for the `home-center.module-contract-admission-binding.v1` evidence introduced in 0.38.0.

The release adds `home-center.module-contract-admission-binding-revalidation.v1` and the deterministic `mcabr-*` identity. Revalidation reconstructs the original `mcab-*` from its exact compatibility profile, contract negotiation and module admission evidence before evaluating fresh evidence.

A binding is `current` only when the reconstructed original and the fresh binding describe the same exact contract/admission state. Changes to the contract profile, negotiation decision, Home Center version, selected contract revisions, module identity/version, manifest binding, verified artifact identity, admission decision or admission outcome make the result `stale`.

Malformed or tampered original evidence and invalid fresh evidence are rejected fail-closed instead of being represented as ordinary drift.

## Safety boundary

Revalidation is evidence-only. It does not authorize module admission, installation, execution, production mutation or external publication.

The contract has no topology-placement semantics and remains compatible with both single-node and HA deployments. It does not add infrastructure-provider assumptions, Jobs/Operations behavior or Cluster/HA orchestration.

No persistent-state migration is required.

## Qualification

The exact release content must pass Home Center CI, public-repository privacy boundary and infrastructure-neutrality checks before promotion. Official publication occurs only after the promoted `main` revision also passes the canonical main-branch release pipeline.
