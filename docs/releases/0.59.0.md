# Home Center 0.59.0 — development notes

Status: **development only**. This document does not declare RC or Stable readiness.

Home Center 0.59 starts Policy Composer v1 on top of the 0.58 managed-device safety
boundary. The first slice is intentionally non-mutating and focuses on a deterministic
policy model that can later be wired into existing DesiredState/Job execution.

Implemented in this non-runner development slice:

- `PolicyBundle` as a reusable household policy restriction set;
- deterministic composition of one or more bundles over the existing role-derived
  `EffectivePolicy`;
- order-independent composition semantics and duplicate-bundle rejection;
- fail-closed monotonicity: a bundle may remove an existing capability, require managed
  devices, or make internet access more restrictive, but may not grant a capability,
  weaken a managed-device requirement, or broaden internet access;
- external publication remains hard-disabled and production mutation remains
  unauthorized;
- a non-mutating `PolicyCompositionPreview` with deterministic identity, exact bundle
  lineage and human-readable field-level restriction changes;
- closed Draft 2020-12 contracts for PolicyBundle and composition preview;
- focused test code for deterministic composition, escalation rejection, managed-device
  monotonicity, duplicate/empty bundle rejection and serialization safety.

This slice deliberately does **not**:

- add RBAC storage or reinterpret Household roles as authorization roles;
- create Family/Group/Device-group persistence or policy-binding storage;
- write DesiredState, start Jobs, mutate devices or call providers;
- enable external publication;
- bypass 0.57/0.58 real-environment and provider qualification gates;
- claim runner qualification, RC readiness, Public Stable readiness or commercial
  clearance.

Next 0.59 slices may add explicit Family/Group/Device-group bindings and compile the
resulting effective policy into the existing DesiredState/Job planning boundary. Those
steps must preserve preview/explanation first, confirmation/step-up where required, and
the 0.58 verified managed-state/read-back guarantees.

Public Stable remains 0.56.0. The active release horizon for this work is limited to
0.57, 0.58 and 0.59.
