# Home Center 0.49.0

Status: source package ready for qualification.

## Scope

Home Center 0.49.0 adds exact-state revalidation for aggregate module
compatibility across multiple Home Services. The source package reconciles the
existing multi-service compatibility contract with the current 0.48 Household
and authenticated API integration line without changing Household behavior.

The new
`home-center.module-home-service-contract-multi-compatibility-binding-revalidation.v1`
contract reconstructs the original aggregate compatibility evidence, computes a
fresh aggregate from the current multi-service requirement set, module-admission
binding and Home Service profiles, and deterministically reports `current` or
`stale`.

Drift is tracked for the exact requirement-set identity, Home Center version,
module identity/version, service set, per-service compatibility evidence,
blocked-service set and aggregate compatibility status. Malformed or tampered
original/fresh evidence is rejected fail-closed.

## Safety boundary

This contract is evidence only. Admission, installation, execution, production
mutation and external publication authority remain false. It adds no
Jobs/Operations behavior, Cluster/HA orchestration, placement semantics or
release-promotion logic. Authentication policy is unchanged and the contract is
topology-neutral and infrastructure-neutral.

No persistent-state migration is required.

## Qualification boundary

Runner-free preparation includes deterministic runtime code, closed JSON Schema
and targeted unit/contract tests. Repository-wide qualification, security and
release promotion remain the responsibility of HC Release Engine A/B.
