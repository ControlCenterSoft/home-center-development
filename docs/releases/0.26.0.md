# Home Center 0.26.0

Status: development qualification candidate.

Home Center 0.26 starts the Household/Intent foundation for the mobile-first
«Уютный» interface without creating a separate execution path or bypassing the
existing safety model. This candidate adds household domain contracts, fixed
household role presets, deterministic effective policy evidence and
side-effect-free intent planning.

## Household domain

The new `home_center.household` runtime defines:

- `Household` as the bounded home context;
- `FamilyMember` as the primary household identity;
- fixed household roles `parent`, `child` and `guest`;
- `ManagedDevice` bound to one exact family member;
- safe role presets and deterministic `EffectivePolicy` evidence.

Household validation fails closed on duplicate members/devices, orphan device
bindings, invalid identifiers and a household with no enabled parent. Member and
device collections are canonicalized by stable identifiers.

Household roles are a domestic policy layer, not a replacement for the product's
professional authorization model. Every preset keeps external publication
disabled. Child and guest presets do not grant administration; the child preset
also requires managed-device policy and uses filtered Internet policy by
default.

## Household/Intent planning

The new `home_center.household_intent` runtime translates supported household
requests into typed `RecommendedAction` plans. The first bounded intents are:

- onboarding a family member with an explicit household role;
- enrolling a device for one exact existing family member.

Only an enabled parent with an effective administration policy can create these
plans. Device enrollment is bound to an exact member and rejects unknown or
disabled subjects. Existing target identifiers are rejected rather than treated
as implicit updates.

Plans are deterministic and explicitly carry:

- `confirmation_required = true`;
- `mutation_authorized = false`;
- `production_mutation_enabled = false`.

Therefore a plan is recommendation/evidence only. It does not create accounts,
change RBAC, configure DNS/VPN/MDM, mutate Desired State, enroll a device or
execute provider commands.

## Contracts and artifact boundary

Closed JSON contracts are added for Household, EffectivePolicy and Household
Intent Plan. Unknown fields are rejected by the contracts and the non-mutation
flags are fixed where applicable.

Release identity is `0.26.0` across `VERSION`, package metadata and runtime
metadata. Artifact qualification now requires both Household runtime modules in
the wheel. No persistent-state or database migration is introduced by this
foundation release; persistence and execution integration remain later bounded
work.

## Cumulative guarantees

Home Center 0.22 execution admission/evidence, 0.23 durable transition
authorization/apply, 0.24 read-back verification/pre-apply audit and 0.25
completion-audit guarantees remain cumulative. Household/Intent does not weaken
those boundaries and does not enable external publication automatically.

The 0.26 branch remains a development candidate until its complete acceptance
and release gates pass.
