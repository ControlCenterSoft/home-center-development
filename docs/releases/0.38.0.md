# Home Center 0.38.0 — binding negotiation и admission

## Состав версии

Версия 0.38.0 добавляет evidence-only связь между versioned module-contract negotiation из 0.37.0 и одним точным module admission decision.

Binding детерминирован и работает fail-closed. Он проверяет канонические identities compatibility profile, negotiation decision и admission decision, требует совместимого negotiation, подтверждает поддержку всех запрошенных revisions точным profile и требует совпадения версии Home Center во всех evidence objects.

Результат `home-center.module-contract-admission-binding.v1` фиксирует точные profile, negotiation, admission, manifest contract revision, module identity, manifest binding digest и artifact digest.

## Граница безопасности

Binding не разрешает admission, installation, execution, mutation, publication или promotion модуля. Поля `admission_authorized`, `installation_authorized`, `execution_authorized`, `production_mutation_enabled` и `external_publication_authorized` остаются `false`.

Версия не добавляет Jobs/Operations, cluster/HA placement или release-promotion behavior. Контракт topology-neutral и infrastructure-neutral.

## Проверка релиза

Обязательные проверки подтверждают syntax/contracts, deterministic behavior, fail-closed tamper rejection и JSON Schema validation. Source package не считается Public Stable до отдельного завершённого qualification/release cycle.
