# Home Center 0.38.0 — contract-negotiation admission binding

## Scope

This source-development slice adds an evidence-only binding between the
versioned module-contract negotiation introduced in 0.37.0 and one exact
module admission decision.

The binding is deterministic and fail-closed. It verifies the canonical
identities of the compatibility profile, negotiation decision and admission
decision, requires a compatible negotiation, requires all requested revisions
to be supported by the exact profile, and requires the Home Center version to
match across all three evidence objects.

The resulting `home-center.module-contract-admission-binding.v1` evidence
records the exact profile, negotiation, admission, manifest contract revision,
module identity, manifest binding digest and artifact digest.

## Safety boundary

The binding does not admit, install, execute, mutate, publish or promote a
module. `admission_authorized`, `installation_authorized`,
`execution_authorized`, `production_mutation_enabled` and
`external_publication_authorized` are always false.

No Jobs/Operations, cluster/HA placement or release-promotion behavior is
introduced. The contract is topology-neutral and infrastructure-neutral.

## Qualification boundary

Runner-free source checks cover syntax, deterministic behavior, fail-closed
tamper rejection and JSON Schema validation. Full repository qualification
remains the responsibility of the Home Center release qualification engines.
