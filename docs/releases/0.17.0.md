# Home Center 0.17.0

Cumulative portable devices and automation release: the 0.16 compute foundation plus a deterministic Device Registry, typed runbook planning, a capability-gated device Automation Engine and a provider-neutral Zigbee pairing boundary.

The 0.17 boundaries fail closed on malformed identities, timestamps, permissions, capabilities and provider observations. Every automation or pairing result is plan-only: production mutation and execution authorization remain disabled, and arbitrary shell commands are outside the public API.

The release depends on the complete 0.15 inventory/discovery/profile foundation and the 0.16 compute and lifecycle-planning boundary. It adds the Device Registry, typed runbook and execution contracts, automation-engine planning and Zigbee pairing capabilities without bypassing the inherited safety model.
