# Home Center 0.17.0

Cumulative infrastructure-neutral release integration for devices and automation.

- Device Registry uses generic device/location/subject identifiers and normalized RFC3339 timestamps.
- Automation is plan-only, capability-driven, and rejects secret-bearing parameters.
- ZigBee is exposed through a provider-neutral coordinator/pairing boundary.
- No specific home, coordinator address, user account, network, or device inventory is compiled into product source.
