# Home Center 0.17.0

Cumulative portable devices and automation release: the qualified 0.16 compute foundation plus a deterministic Device Registry, typed runbook planning, a capability-gated device Automation Engine and a provider-neutral Zigbee pairing boundary.

The 0.17 boundaries fail closed on malformed identities, timestamps, permissions, capabilities and provider observations. Every automation or pairing result is plan-only: production mutation and execution authorization remain disabled, and arbitrary shell commands are outside the public API.

Integration order is strict: qualified 0.15 inventory/discovery/profile support, then qualified 0.16 compute and lifecycle planning (`9c3cb4ca489166e1166a81510f9e9aee98cd22da`), then the isolated 0.17 runbook, execution API, Device Registry, automation-engine and Zigbee increments. A 0.17 release must not enter a release channel until its 0.16 dependency is accepted there.
