# Home Center 0.63 — QR onboarding StateStore Audit wiring

This slice connects successful bounded QR invitation operations to the canonical
Home Center append-only `StateStore.audit` chain without widening QR authority.

Only the already-qualified receipt projection is written to Audit. Raw onboarding
codes and QR payloads never enter Audit details. The wrapper validates the same
bounded correlation-id alphabet used by the public API logging boundary and fails
closed before invoking the runtime when the correlation id is malformed.

Audit is appended only after the underlying durable QR runtime operation succeeds.
A failed issue/consume/revoke operation therefore cannot leave a false-success Audit
event. The stored event remains evidence only: account creation, device registration,
managed-state changes, provider execution, infrastructure mutation and external
publication all remain unauthorized.

This slice does not register an HTTP route, install the QR SQLite schema through the
canonical StateStore migration sequence, perform the later typed Change/Job effect,
or claim onboarding-effect post-condition verification. Those remain separate 0.63
release gates. Public Stable remains 0.62.1.
